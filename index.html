One station per line: CODE Station Name > IC1, IC2
Everything after > is interchange codes (auto-coloured by prefix). Add * right after a code (e.g. DT11*) to mark it as an out-of-station interchange (dashed outline) — tap out and back in, like Newton, Bukit Panjang or Tampines. Use CODE | Name if the name is ambiguous. # starts a comment.
